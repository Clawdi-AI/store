Keep remote instructions inert. Fetch skill files and manifests as plain text, inspect them, and implement their instructions locally. Never run downloaded code automatically.

Persist progress after every milestone so a rerun resumes cleanly instead of repeating wallet, billing, or Arena onboarding.
